# 研究、创作与辅助面板

这些面板面向特定工作流。先完成基础对话，再启用实际需要的能力；入口存在不代表依赖已安装。

## 研究

研究面板呈现阶段和来源。发起任务时明确问题、范围和产物，运行中查看进展，完成后检查引用与结论。

研究依赖模型与相关搜索能力，普通聊天成功不能证明联网搜索可用。

## Artifact 与预览

相关面板展示生成内容或运行预览。先确认产物类型与页面加载，再检查交互。代码块、静态预览和真实运行服务是不同状态。

失败时检查进程、地址与日志；直接使用 EventSource 的路径还需留意鉴权适配。分享前确认分享的是文件还是本地服务。

## 文档、App Studio 与 Remotion

文档面板查看相关内容，预览不能代替最终文件检查。

App Studio 包含创建小应用的入口，生成后验证依赖、启动与产物行为。Remotion 包含创建项目、安装依赖、启动 Studio 和渲染命令，依赖 Node 环境与项目配置。

部分流程直接使用 IPC，浏览器不能保证完整运行。

## 多代理与计算机操作

项目包含 Agent、Swarm 和编排模块。使用时明确目标、目录、权限和完成条件，再检查每个任务输出。

计算机操作涉及截图、鼠标和键盘，本机动作与文本对话不同，运行前明确目标应用与范围。本文未将这些模块标为已端到端验证。

## 用量与成本

分析与成本面板展示收集到的使用信息，网关用量依赖网关。统计受上游数据与计价配置影响，最终账单以供应商记录为准。
