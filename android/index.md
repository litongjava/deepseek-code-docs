# Android 使用指南

DeepSeek Code 的 Android 应用把桌面工作台带到手机和平板：复用同一套聊天界面与 Rust 引擎，支持会话、项目、模型供应商、工具审批和交互终端。应用自带引擎，本机模式无需启动电脑或服务器，也无需 Root；模型回答仍需连接你配置的模型服务。

## 选择使用方式

- **在手机上处理项目**：安装 APK 后直接使用本机模式，文件、命令和会话保存在手机上，见[首次使用与开发环境](./usage.md)。
- **继续电脑上的工作**：应用连接 `dcd-server`，使用服务器上的项目、工具和会话，见[连接服务器](./usage.md#连接服务器)。
- **只用手机浏览器**：打开服务器网页即可，见[在浏览器和手机上使用](../desktop/guide/web-and-mobile.md)。
- **习惯命令行**：在 Termux 中运行独立的 dcl，见[Android CLI](../cli/android.md)。

## 安装与开始

1. 获取与你的设备架构匹配、由可信来源签名的 APK。自己编译的步骤见[构建与安装](./build.md)。
2. 安装并打开应用，进入聊天页；按系统提示允许任务通知。
3. 在用户菜单的“设置”中打开 Models，添加模型供应商的地址、密钥和模型，并保存。
4. 返回聊天页选择模型，发送“回复 OK”，确认可以逐字收到回答。
5. 首次启动会在后台下载约 30 MB 的 Ubuntu 基础环境。就绪后打开右侧 Terminal，运行开发命令。

环境准备期间，命令使用 Android 自带的 Shell；Ubuntu 就绪后，模型 Bash 工具和交互终端共用 Ubuntu 软件环境。安装软件的命令见[首次使用](./usage.md)。
