# `@` 引用文件

在提示词里写 `@路径`，可以把项目里的文件或目录一起交给模型，模型不需要再调用 Read 读取。

## 补全

输入 `@` 后接文件名的一部分，会弹出项目文件列表：

```text
> 解释一下 @ma
› @src/main.rs
  @README.md
↑↓ select · Tab/Enter complete · Esc close   1–2 / 2
```

- **候选排序**：路径前缀匹配优先，其次是文件名前缀，再次是包含关系，最多列出 50 个。
- **补全方式**：`Tab` 或 `Enter` 只替换当前这个 `@` 词，前面已输入的内容保留。
- **扫描范围**：每次打开输入框时扫描一次项目目录，最多 20000 个文件。跳过隐藏目录，以及 `node_modules`、`target`、`dist`、`build`、`out`、`__pycache__`、`vendor`。

## 发送时附带的内容

| 引用的是 | 附带内容 |
|---|---|
| 文本文件，200 KB 以内 | 文件全文，放在 `<mentioned-file path="...">` 中 |
| 目录 | 前 100 个条目的列表，放在 `<mentioned-directory path="...">` 中 |
| 图片（PNG、JPEG、GIF、WebP） | 作为图片发送，见[图片](./images.md) |
| 二进制文件、超过大小、不存在 | 不附带，`@` 文字原样保留 |

- **数量上限**：一条提示词最多附带 10 个文件或目录。
- **标点处理**：路径后面紧跟的逗号、句号、括号等会被忽略，例如 `@src/main.rs,` 可以正常识别。
- **路径解析**：相对路径以项目目录为准。
