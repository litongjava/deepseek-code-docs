# 生成和编辑图片

`ImageGenerate` 让对话模型通过当前提供商的图片接口生成 PNG，也可以按原顺序提供最多五张参考图片进行编辑。生成结果保存到工作目录，并作为真实图片交回模型；原有图片输入和识图流程继续可用。

例如，可以请求：

```text
生成一张简洁的青色圆形图标，白色背景，保存为 assets/icon.png。
```

或者指定参考图片：

```text
参考 assets/icon.png，把圆形改为蓝色，保存为 assets/icon-blue.png。
```

工具使用 `gpt-image-2`，新建图片调用当前 Base URL 后的 `/images/generations`，编辑调用 `/images/edits`。例如 Base URL 为 `http://127.0.0.1:8318/tools/codex/v1` 时，请求仍只发送到该代理。模型账号、OAuth 刷新和图片服务路由均由代理负责。

输出必须是一个尚不存在的 `.png` 文件；目录可包含中文和空格。工具支持透明背景以及服务端支持的尺寸和质量参数。参考图片支持 PNG、JPEG、WebP，每张最多 32 MiB。

生成最多等待 600 秒。收到完整且格式符合要求的图片数据后才保存文件，不覆盖已有文件，不自动重试付费生成。失败会报告接口状态，取消或响应不完整时不会留下半成品图片。

图片生成需要代理实际提供对应图片接口和可用的上游账号。聊天模型可用不代表图片服务一定可用；实际成功应以返回并保存的图片为准。
