# 图片

交互模式下，可以把图片和提示词一起发给模型，例如截图、设计稿、报错界面。

## 发送图片的三种方式

1. **拖入终端**：把图片文件拖进终端窗口，或粘贴一个图片文件的绝对路径。和 Claude Code 一样，输入框里显示为 `[Image #1]`。
2. **写路径**：直接写图片路径，或写 `@图片.png`。路径可以带引号，也可以是绝对路径。
3. **粘贴剪贴板图片**：截图后在输入框按 `Ctrl+V`，dcl 会把图片保存到[数据目录](./data-directory.md)的 `pasted-images/` 下，并插入 `[Image #1]`。

```text
❯ 这个页面哪里对不齐？ [Image #1]
```

- 编号在本次会话内递增；同一张图片再次粘贴时沿用原来的编号。
- 发送时，`[Image #N]` 对应的图片随提示词一起发给模型；删掉占位符就不再附带这张图片。
- 和 Claude Code 一样，发送后提示词下方显示 `⎿  [Image #1]`，表示附带了哪些图片。
- 模型运行中在输入框里粘贴图片也会显示为占位符；模型在本轮中途读到这条消息时，图片一并交给模型。

## 规则

- **格式与大小**：支持 PNG、JPEG、GIF、WebP；每张不超过 5 MB；一条提示词最多 5 张。
- **同时附带文件**：同一条提示词里 `@` 引用的其他文本文件照常附带，见[`@` 引用文件](./file-mentions.md)。
- **模型要求**：所有模型默认允许发送图片，`supports_vision` 默认值为 `true`。图片是否可处理由服务端判断；若不支持，会显示服务端返回的错误。旧的本地能力标记不会阻止图片发送。
- **仅限交互模式**：`dcl -p` 不处理图片路径。

## 剪贴板依赖

粘贴图片依赖系统工具：

| 系统 | 需要的工具 |
|---|---|
| Linux（Wayland） | `wl-paste`（wl-clipboard） |
| Linux（X11） | `xclip` |
| macOS | `pngpaste`（`brew install pngpaste`），没有时用系统自带的 `osascript` |
| Windows | 无需额外工具，dcl 直接读取剪贴板 |

Windows 上 dcl 直接读取剪贴板，响应迅速：浏览器、截图工具复制的 PNG、位图，以及在资源管理器里复制的图片文件都能粘贴。有的终端会把 `Ctrl+V` 留作自己的文字粘贴，这时改按 `Alt+V`，效果相同。

剪贴板里没有图片时，`Ctrl+V` 粘贴剪贴板里的文字；终端自己完成文字粘贴时照常进行，粘贴的内容不是单个图片文件的路径时也照原样插入。
