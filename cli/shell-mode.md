# `!` 命令模式

在输入框里以 `!` 开头，后面的内容会直接在你的 Shell 里运行，不经过模型。命令和输出会加入对话，模型下一轮可以用到。

```text
❯ !git status --short
! git status --short
  ⎿  M src/main.rs
     ?? notes.md
❯ 把刚才 git status 里改动的文件总结一下
```

## 行为

- **运行环境**：在当前项目目录中运行，读取与 dcd 共用的 `shell.terminalDefault` 设置。`auto` 保留平台默认行为；选择 `bash` 时使用配置的 Bash 路径，选择 `wsl` 时使用明确指定的发行版。详见 [Shell 配置](./settings.md#shell-配置)。
- **不需要审批**：这是你自己输入的命令，所以不经过权限检查，和 Claude Code 一致。
- **显示输出**：标准输出和错误输出显示在命令下方，失败时附上退出码。输出纳入界面历史，回到输入框后仍可滚动查看；直接拖选并松开鼠标即可复制。
- **进入上下文**：命令和输出以 `<bash-input>` / `<bash-stdout>` / `<bash-stderr>` 的格式记入对话，每部分最多保留 30000 个字符。
- **中断**：`Ctrl+C` 中断正在运行的命令。
- **没有标准输入**：需要交互输入的命令无法使用，例如 `vim`、`ssh` 登录。

输入以 `!` 开头时，输入框下方会提示 `! shell mode`。
