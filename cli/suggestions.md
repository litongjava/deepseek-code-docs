# 建议补全

一轮结束后，dcl 会预测你接下来最可能输入的话，以灰色文字显示在空的输入框里。合适就按 `Tab` 接受，不合适直接输入别的内容即可。

```text
● Changed 1 file (+1) · Ctrl+O shows the diffs
    hello.py  +1
Worked for 4s · done · 6:15 PM
──────────────────────────────────────────────
> now run it
──────────────────────────────────────────────
ask mode (Shift+Tab to cycle) - Tab accepts the suggestion - Enter send
```

## 操作

| 按键 | 作用 |
|---|---|
| `Tab` 或 `→` | 把建议填入输入框，可以继续修改后再发送 |
| 直接输入 | 建议消失，按你输入的内容为准 |
| `Enter`（未接受时） | 发送空输入，不会发送建议 |

建议只在输入框为空时显示。在建议生成出来之前你已经开始输入的话，它就不会再出现。下一轮开始时，上一轮的建议会被丢弃。

## 建议从哪里来

每轮结束、并且最后一条是模型的回答时，dcl 在后台向当前模型发一个很小的请求：
- **请求内容**：最近 6 条消息（每条截取前 1500 个字符），加一段说明。说明要求模型预测"你自己接下来会输入的话"，而不是它认为你该做的事。
- **不使用任何工具**，最多等 30 秒，失败时什么都不显示。

预测规则参照 Claude Code：

- 2 到 12 个词，语气和语言跟你保持一致，例如"run the tests"、"commit this"、"提交并推送"；
- 下一步不明显，或者刚发生了错误时，**不给建议**；
- 会被过滤掉的内容：评价（"looks good"）、提问、用助手口吻的话（"Let me…"）、你没提过的新想法、多句话。

每条建议都会产生一次额外的模型请求，按当前模型计费。

## 关闭

在[数据目录](./data-directory.md)的 `settings.json` 中设置：

```json
{ "promptSuggestionEnabled": false }
```
