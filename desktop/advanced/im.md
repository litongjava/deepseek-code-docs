# IM 集成

面板提供平台配置、连接状态、权限、统计和日志。平台的认证与通信不同，应分别验证。

## 配置入口

当前界面列出 Telegram、飞书、微信、钉钉及飞书 Bridge。

- Telegram：Bot Token 与可选 Webhook URL。
- 飞书、微信、钉钉：各自 Webhook URL 与部分可选 Token 字段。
- 飞书 Bridge：独立连接流程，按入口呈现的步骤配置。

按平台要求取得凭据。不要互换平台 Webhook，也不要把“微信”入口理解为支持所有个人微信接入方式。

## 验证顺序

1. 选择平台并补齐字段。
2. 保存并启动连接。
3. 查看状态与错误日志。
4. 发送测试前明确目标 Chat ID 和收件范围。
5. 在平台侧确认收到消息，再单独验证入站消息和权限。

Webhook 发送成功不代表双向聊天已可用，连接正常不能替代完整消息测试。

## 访问权限

界面提供开放、白名单和配对码模式，按使用范围选择并核对允许对象与待处理请求。

IM 权限控制谁能访问机器人；本机工具权限需要另行配置，两者不能互相替代。

## 排查问题

检查日志、凭据、平台权限、地址和网络。需平台回调本机时，应提供平台可达的部署地址，本地 `127.0.0.1` 不能直接接受外部平台访问。

本章基于源码整理，未做真实平台发送测试。源码参考：`IMIntegrationPanel.tsx`、`crates/core/src/im_integration`、`src-tauri/src/bridge/routes/im.rs`。
