# 定时任务

设置的任务页用于创建调度任务、管理任务与查看运行记录。先了解各类型的实现程度。

## 创建任务

填写名称、可选说明、Cron、任务类型、任务配置，以及可选会话 ID。表单提供每分钟、每小时和每天等预设。

保存后检查下一次时间和实际执行记录。调度代码使用 UTC 计算，不要直接把 `0 9 * * *` 当作当地上午 9 点。

## 类型的实际状态

**Send Prompt**：执行器返回包含配置的占位文字，不能当作已经向模型发出提示词。

**Generate Report**：同样是占位结果，不代表已生成真实报告。

**Webhook Call**：后端解析 JSON 配置并发起 HTTP 请求，使用前核对目标服务要求和接收结果。

**System Command**：通过系统 shell 执行，并包含危险命令检查。应明确执行位置、参数与内容，执行状态成功不等于产物符合预期。

这些差异依据 `src-tauri/src/scheduler/mod.rs`，不是从界面名称推断的功能承诺。

## 运行与排错

调度依赖应用后端。没有独立常驻服务时，不要期待关闭应用后仍按时执行，也不要假定休眠后自动补执行。

检查启用状态、下一次时间、输出和错误。无记录先查进程与时区，有记录但结果错误则检查具体执行器。
