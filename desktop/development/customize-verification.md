# 自定义入口验证

## 2026-11-03 更新：统一概览与管理入口

概览卡片与左侧二级导航均按 **Skills → MCP → Connectors → Plugins** 排列，使用一致的图标容器、标题与描述、尺寸、圆角、箭头及键盘焦点样式。点击概览 Skills 进入技能管理，不再直接创建；需要创建时，在技能管理中点击加号并选择“编写技能指令”。

Skills 读取本地 Bridge 的真实技能列表，按内置与用户技能分组。选择技能可查看内容和启停；用户技能可通过“编辑详情”修改名称、描述和指令并保存。创建后使用后端返回的身份、内容和启用状态；保存后重新读取持久化结果。读取或写入失败会显示错误，不再静默显示空列表或假成功。

MCP 复用现有原生管理页面。变更后同时刷新服务和工具列表；读取错误可重试，保存失败保留表单。配置方法见 [MCP 服务](../configuration/mcp.md)。

本次验证区分两层：

- Skills HTTP 集成测试使用临时数据目录，验证创建、列表、详情、保存、启停、删除及失败状态码，不操作用户技能。
- dsb 有头 Chrome 使用实际页面组件与明确隔离的模拟响应，检查 1664×937 和 1280×800 布局、四项顺序、统一卡片尺寸、Skills/MCP 跳转及 Tab/Enter 焦点导航；两种视口无页面横向溢出。浏览器检查不是原生 MCP 启停或工具调用验收。

开发脚本、测试记录与截图保存在独立开发支持目录；下方截图和统计保留为历史记录。


## 验证范围

2026-10-14，在本地前端开发页面使用 deepseek-browser-use CLI 操作有头 Chrome。测试过程显示浏览器窗口，截图位于文档项目的 `assets` 目录。

验证目标为扩展菜单、自定义的四项导航、插件分类搜索，以及 Settings 内嵌页面。插件当前仅提供分类浏览。MCP 页面沿用桌面 IPC，浏览器验证只检查入口和页面，不代表原生服务启动、停止或工具调用已验证。
