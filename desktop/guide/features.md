# 功能地图与阅读路线

使用客户端的核心流程是：安装 → 配置模型 → 开始聊天 → 按任务引入项目和工具。开发环境与文档站部署不是普通使用者的前置步骤。

## 基础能力

**聊天与会话**：选择模型、发送消息、查看流式回复、整理历史会话。先阅读[聊天指南](../usage/chat.md)。

**模型配置**：管理服务地址、API 格式、凭据和会话可选模型。见[模型供应商](../configuration/models.md)。

**项目**：用名称、目标、说明和相关文件组织长期工作。项目记录与实际文件工作目录需要分别确认，见[项目工作流](../usage/projects.md)。

## 工具与上下文

技能、MCP、连接器和插件统一放在“自定义”中，可从“扩展 → 自定义”或“设置 → 自定义”进入，见[自定义指南](../usage/skills.md)。扩展菜单不再显示“目录”和独立 MCP。

**MCP**：连接工具服务，管理启停并查看工具列表。需要服务命令、运行时及可能的环境变量，见[MCP 配置](../configuration/mcp.md)。

**Skills**：维护可复用的任务说明，在对话中使用。Skills 与 MCP 不是同一种配置，见[自定义指南](../usage/skills.md)。

**知识库**：管理标题、Markdown 内容、标签以及关系图。**记忆**：检索与管理记忆上下文，依赖对应后端。见[知识库与记忆](../usage/knowledge.md)。

## 可选与进阶能力

- [定时任务](../advanced/tasks.md)：任务调度与运行记录，其中 Prompt、Report 执行器当前仍是占位实现。
- [IM 集成](../advanced/im.md)：平台连接、权限、统计和日志；各平台需单独验证发送和接收。
- [辅助工作台](../advanced/workbench.md)：研究、Artifact 预览、文档、App Studio、Remotion、成本分析和多代理相关入口。

界面里出现功能入口，不代表外部服务已配置。各章提供使用顺序、前置条件和检查点。

## 按角色阅读

一般使用者：首次使用 → 模型配置 → 聊天 → 项目 → 备份。

高级使用者：工具权限 → MCP → Skills → 知识库 → 所需的进阶功能。

开发者：从源码运行 → 通信架构 → 源码导航 → 浏览器调试 → 相关功能测试。
