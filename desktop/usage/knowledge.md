# 知识库与记忆

知识库主动整理资料，记忆检索与管理对话上下文，二者也与聊天历史不同。

## 添加知识条目

新建条目并填写标题、正文和逗号分隔的标签，也可使用粘贴 Markdown 的导入入口。

保存后搜索关键词，打开核对正文，再切换列表与关系图。条目包含链接与反向链接，关系图观察已有关系；没有连线不等于导入失败。

组件直接调用 `kb_*` Tauri 命令，建议在桌面窗口使用。

## 记忆管理

从侧边栏打开**长期记忆**，可以：

- 浏览最近的记忆，或按关键词搜索，支持中英文。
- 手动添加重要的事实，并设置重要性。
- 编辑或删除单条记忆。删除前会请求确认。
- 导入、导出 JSON，导入前可以先预览。
- 调整设置：启用状态、自动保存、自动检索、每次检索的条数和最低重要性。

![长期记忆面板](/desktop-memory-list.png)

点击条目右上角的铅笔编辑，垃圾桶删除：

![编辑一条记忆](/desktop-memory-edit.png)

记忆保存在本机，Desktop 和 [dcl](/cli/memory) 共用同一份数据，任一端的修改另一端都能看到。

单条编辑和删除使用本机存储。连接外部记忆服务时，可以搜索、添加和清空，单条管理由该服务负责。

## 数据处理

删除条目或清空记忆前确认保留需求。知识库、MemEx 和会话 SQLite 可能位于不同位置，备份应覆盖实际数据源。
