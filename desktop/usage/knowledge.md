# 知识库与记忆

知识库主动整理资料，记忆检索与管理对话上下文，二者也与聊天历史不同。

## 添加知识条目

新建条目并填写标题、正文和逗号分隔的标签，也可使用粘贴 Markdown 的导入入口。

保存后搜索关键词，打开核对正文，再切换列表与关系图。条目包含链接与反向链接，关系图观察已有关系；没有连线不等于导入失败。

组件直接调用 `kb_*` Tauri 命令，建议在桌面窗口使用。

## 记忆管理

面板提供搜索、统计、配置和上下文信息。先确认后端健康，再搜索已知内容，查看重要性与相关度。

配置包括启用状态、后端地址、自动摄入、自动搜索、搜索条数、压缩阈值与最低重要性阈值。增加检索内容也可能增加上下文。

## 当前依赖限制

MemEx 是额外的记忆后端。此前本机日志显示缺少 `src-tauri/memex/api.py`，相关能力被禁用。这不能靠反复切换开关解决。

需先补齐项目支持的服务和配置，再验证健康、写入与检索。本文不提供未经核实的服务下载地址。

## 数据处理

删除条目或清空记忆前确认保留需求。知识库、MemEx 和会话 SQLite 可能位于不同位置，备份应覆盖实际数据源。
