# 安装客户端

本章面向使用应用的读者。已有可信的 Windows 安装包时，无需先安装 Node.js、Rust 或文档站。

## 安装前准备

准备与系统架构匹配的客户端安装包，以及可用的模型服务账号或 API 凭据。桌面界面需要 WebView2 Runtime；涉及 Git 和命令行工具的工作流还可能需要 Git for Windows / Git Bash。

当前源码包含 Windows 专属依赖，本文以 Windows 为主，不承诺其他平台可直接安装或构建。

## 使用安装包

1. 从项目维护者提供的可信位置取得发布包，确认版本和系统架构。
2. 如果拿到 Windows 安装程序，按照该安装程序的实际提示安装。
3. 启动客户端，完成主题、运行模式和工作目录引导。
4. 按[模型配置](../configuration/models.md)接入服务，发送简单消息确认可用。

本文未核实公开发布下载地址，因此不提供猜测的下载链接。手中只有源码时，使用[从源码运行](./quick-start.md)；维护者可运行 `npm.cmd run tauri build` 构建分发包，安装包类型以实际构建产物为准。

## 验收安装

窗口能打开，说明桌面运行环境基本就绪；还应检查模型列表、首次对话和会话切换。文件工具需要进一步验证工作目录与 Git Bash。

窗口空白时检查 WebView2 和日志。窗口正常但聊天失败时，优先排查模型配置和网络，不必立即重新安装。

## 更新与卸载

更新前备份本地数据，再使用维护者提供的新版本。项目有更新相关模块，但自动更新是否可用取决于发布端配置，不能把入口存在视为已部署更新服务。

卸载客户端与删除用户数据是两件事，不要假定卸载会清空数据。备份和迁移见[数据维护](../maintenance/data.md)。
