# 常见问题

## 安装包用户也要安装 Rust 吗？

不需要。Rust 和 Node.js 是源码开发环境要求；安装包主要需要系统运行条件。外部工具可能仍需自己的 Node、Python 或 Git。

## 自托管就是完全离线吗？

不是。它使用自己配置的服务；远程供应商仍需网络。只有实际使用本机模型及兼容能力时，才可能形成相应离线流程。

## 添加供应商后，聊天选择器没有模型？

检查模型列表，并把模型加入聊天列表或档位。显示名称与实际 ID 不同，后者必须受上游支持。

## 浏览器能打开页面却不能用全部功能？

浏览器能调用已有 HTTP 接口，但没有 Tauri IPC 与安全存储环境。见[浏览器调试](../development/browser.md)。

## Tauri IPC 是 WebSocket 吗？

不是，它使用原生 WebView 桥接。聊天主要用 HTTP 与 SSE；开发环境的 `5201` WebSocket 用于 Vite 热更新。

## 知识库、记忆与会话有什么不同？

知识库主动整理资料，记忆检索上下文，会话保存对话。不同模块有各自后端与配置，见[知识库与记忆](../usage/knowledge.md)。

## 定时任务成功却没调用模型？

Prompt 与 Report 当前执行器仍返回占位结果，见[定时任务](../advanced/tasks.md)。

## 创建项目会自动读取全部文件吗？

不能假定。说明、附件和实际目录需要分别确认，读取行为取决于工具调用和权限。

## 怎么交付给别人？

桌面使用交付安装包与模型配置说明。完整浏览器版还需 IPC 适配、认证与服务部署。发布本文档站只发布说明。

## 仍未解决？

查看[故障排查](../development/troubleshooting.md)，记录版本、模式、操作、错误与日志。先区分界面、本地 Bridge、模型供应商和可选服务，再定位模块。
